# Chelonia Tours

A responsive static website for mangrove and wildlife tours in Tamarindo, Costa Rica. The website's primary language is English (`lang="en"`); visitors can use their browser's Google Translate feature to translate it into Spanish.

## Open the website

Open `index.html` in a browser. No dependencies or server are required.

## Contents

- `index.html`: experience, three tour tabs with photo carousels, gallery, guide, Google Maps location and booking sections.
- `styles.css`: responsive styles, animations, navigation, tour tabs, photo carousels and floating WhatsApp button.
- `script.js`: mobile navigation, accessible tour tabs and carousels, and photo lightbox. Tour carousels advance every five seconds, offer arrow and dot controls, pause during pointer or keyboard interaction, and respect reduced-motion preferences.
- `assets/`: photos from the public Tamarindo Mangrove galleries, including three images for each tour carousel.

WhatsApp booking links use the number published by Chelonia Tours: `+506 8433 0291`. The reference site did not expose public embedded videos or video files, so this version does not include videos.

## Customize

Update the business name, copy, WhatsApp number and photos in `index.html`. Visual styles are in `styles.css`.

Wildlife sightings are unpredictable; the website does not guarantee them and encourages respectful viewing distances.

Tour details and listed per-person prices are based on the public tour pages and should be confirmed with the guide before booking. Tour seasons and wildlife activity may change.
